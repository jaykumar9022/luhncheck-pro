# LuhnCheck Pro

**Validate with Confidence. Understand Every Digit.**

LuhnCheck Pro is a modern, privacy-first validation toolkit built with HTML, CSS, and JavaScript. It provides an intuitive fintech-inspired interface for validating numbers, generating check digits, visualizing checksum calculations, and performing batch validation.

🌐 **Live Demo:** https://jaykumar9022.github.io/luhncheck-pro/

## ✨ Features

- **Luhn Validator** – Validate numbers using the Luhn algorithm.
- **Checksum Visualizer** – Understand the calculation step by step.
- **Fix Finder** – Explore possible checksum-valid corrections.
- **Batch Validator** – Validate multiple numbers together.
- **Check Digit Generator** – Generate valid check digits.
- **Validation History** – Review previous checks with masked numbers.
- **Other ID Checksums** – Explore additional checksum utilities.
- **Premium UI** – Responsive fintech-inspired design with dark and light themes.

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Web Crypto API

## 🚀 Getting Started

No installation or build tools are required.

1. Clone the repository:

   ```bash
   git clone https://github.com/jaykumar9022/luhncheck-pro.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

## 🔒 Privacy & Security

- Validation runs locally in your browser.
- No backend is required for core validation.
- History uses browser storage and masks displayed numbers.
- Use dummy data for testing.

**Disclaimer:** A successful checksum does not confirm that a card or identification number is genuine, active, or officially verified. This project is intended for educational and demonstration purposes only.
